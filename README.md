# `my_sort`

Утилита для сортировки списков с помощью алгоритма **smoothsort** (плавная
сортировка Дейкстры). Поддерживаются числа и строки, сортировка по ключу,
обратный порядок, чтение из файла или стандартного ввода, запись результата,
генерация случайных данных и визуализация процесса сортировки.

## Требования

- Python 3.8 или новее;
- для визуализации: `matplotlib`;
- для звукового сопровождения: `numpy` и `sounddevice`.

Без параметра `--visualize` достаточно стандартной библиотеки Python.

## Запуск

Из корневой папки проекта:

```text
python my_sort.py [элементы] [параметры]
```

Справка по всем параметрам:

```text
python my_sort.py --help
```

## Быстрые примеры

Отсортировать элементы по возрастанию:

```text
python my_sort.py 8 3 10 1
```

Результат:

```text
1 3 8 10
```

Отсортировать по убыванию:

```text
python my_sort.py 8 3 10 1 --reverse
```

Отсортировать строки:

```text
python my_sort.py banana apple cherry --type str
```

Передать данные через конвейер:

```text
echo 9 2 7 1 | python my_sort.py
```

## Источники и вывод данных

Если источник не указан, элементы берутся из позиционных аргументов. Также
можно использовать файл или стандартный ввод:

```text
python my_sort.py --input input.txt
python my_sort.py --input input.txt --output output.txt
```

Файл читается как набор элементов, разделённых пробелами или переводами
строки. При использовании `--output` результат записывается по одному
элементу в строке. Если `--output` не задан, результат выводится в консоль.

Случайный список из 10 целых чисел от 0 до 100:

```text
python my_sort.py --random 10
```

Задать диапазон и seed для повторяемого результата:

```text
python my_sort.py --random 10 --min -50 --max 50 --seed 42
```

## Основные параметры

| Параметр | Назначение |
| --- | --- |
| `values` | Элементы для сортировки |
| `-r`, `--reverse` | Сортировка по невозрастанию |
| `-k`, `--key KEY` | Функция, по результату которой сравниваются элементы |
| `-c`, `--cmp EXPR` | Пользовательское сравнение двух элементов |
| `-t`, `--type TYPE` | Тип элементов: `auto`, `int`, `float` или `str` |
| `-i`, `--input FILE` | Прочитать элементы из файла |
| `-o`, `--output FILE` | Записать результат в файл |
| `--random N` | Сгенерировать `N` случайных целых чисел |
| `--min VALUE` | Минимум для `--random`, по умолчанию `0` |
| `--max VALUE` | Максимум для `--random`, по умолчанию `100` |
| `--seed VALUE` | Seed генератора случайных чисел |
| `-v`, `--visualize` | Показать анимацию сортировки |
| `-s`, `--sound` | Включить звук в визуализации |
| `--delay MS` | Задержка между кадрами в миллисекундах, по умолчанию `200` |

## Типы элементов

По умолчанию (`--type auto`) программа пытается преобразовать входные
значения в `int`, затем в `float`. Если преобразование не удалось, значения
остаются строками.

Тип можно указать явно:

```text
python my_sort.py 10 2 3 --type int
python my_sort.py 1.5 0.25 10 --type float
python my_sort.py 10 2 3 --type str
```

## Сортировка по ключу

Параметр `--key` задаёт функцию для получения значения, используемого при
сравнении. Доступны встроенные варианты:

- `len` — длина значения;
- `abs` — модуль числа;
- `lower` — перевод строки в нижний регистр;
- `upper` — перевод строки в верхний регистр;
- `int`, `float`, `str`, `min`, `max`, `sum`, `sorted`.

Примеры:

```text
python my_sort.py pear apple fig --type str --key len
python my_sort.py -5 2 -10 3 --key abs
python my_sort.py A b C a --type str --key lower
```

Можно передать lambda-выражение:

```text
python my_sort.py 10 2 30 4 --key "lambda x: x % 10"
```

## Пользовательское сравнение

`--cmp` принимает lambda-выражение от двух аргументов. Оно должно вернуть
`True`, если первый аргумент меньше второго:

```text
python my_sort.py 1 2 3 4 --cmp "lambda a, b: a % 2 < b % 2"
```

Для выражений `--key` и `--cmp` используется ограниченное окружение без
доступа к обычным встроенным функциям Python.

## Визуализация

Показать анимацию работы smoothsort:

```text
python my_sort.py 8 3 10 1 5 --visualize
```

Добавить звуковое сопровождение и изменить задержку:

```text
python my_sort.py --random 20 --seed 7 --visualize --sound --delay 100
```

Визуализация открывает окно `matplotlib`, поэтому для неё должны быть
установлены дополнительные зависимости:

```text
pip install matplotlib numpy sounddevice
```

Параметр `--sound` используется вместе с `--visualize`.

## Использование как модуля

Функция `my_sort()` возвращает новый отсортированный список и не изменяет
исходный:

```python
from my_sort import my_sort

numbers = [8, 3, 10, 1]
result = my_sort(numbers)

print(result)  # [1, 3, 8, 10]
print(numbers)  # [8, 3, 10, 1]
```

Сигнатура:

```python
my_sort(array, reverse=False, key=None, cmp=None)
```

- `array` — исходная последовательность;
- `reverse=True` — сортировка по убыванию;
- `key` — функция получения ключа сортировки;
- `cmp` — функция сравнения `cmp(a, b)`, возвращающая `True`, если `a < b`.

Пример с ключом:

```python
result = my_sort(["pear", "apple", "fig"], key=len)
print(result)  # ["fig", "pear", "apple"]
```

При одинаковых ключах сохраняется исходный порядок элементов.
